# 🛡️ 방어적 리스크 인디케이터: LPPL 고도화 모델 (Defensive LPPL Engine)

## 1. 설계 철학 (Design Philosophy)
본 시스템은 **"예측이 아닌 필터링"**을 목적으로 합니다. LPPL 패턴은 자산 가격의 초지수적 성장이 한계에 도달할 때 나타나는 독특한 진동을 포착합니다. 새로운 엔진은 **방어적 리스크 관리**를 위해 다음과 같은 철학을 따릅니다.

- **가짜 신호 최소화 (Minimize False Positives)**: 모든 조건이 완벽하지 않으면 리스크 점수를 과감하게 낮춥니다.
- **방어적 필터 (Defensive Filter)**: 공격적인 매수 신호가 아닌, 시장이 통계적으로 위험한 구역(Dangerous Phase)에 진입했는지 판단하는 필터로 작동합니다.
- **멀티플리케이티브 로직 (Multiplicative Logic)**: 각 리스크 팩터를 더하는 것이 아니라 곱하여, 하나라도 결격 사유가 있으면 전체 점수가 붕괴하도록 설계되었습니다.

## 2. 핵심 아키텍처 및 변경사항 (Core Updates)

### 2.1 멀티플리케이티브 스코어링 (Multiplicative Scoring)
최종 리스크 점수(0-100)는 다음의 구성 요소들을 곱하여 산출됩니다.
$$Risk = \sqrt{Regime \times Fit \times Stability \times Timing \times Consistency} \times Macro \times 100$$
- **하나의 요소가 0에 가까우면 전체 점수가 즉시 하락**하여, 불확실한 구간에서의 오작동을 방지합니다.

### 2.2 레짐 하드 게이트 (Regime Hard Gate)
LPPL 분석이 유의미한 구간에서만 점수가 발생하도록 강력한 필터를 적용합니다.
- **Trend**: 가격 > MA200 (장기 추세 상향)
- **Momentum**: MA50 > MA200 (단기/장기 정배열 가속)
- **Volatility**: 최근 변동성이 역사적 평균 대비 확장 중인 국면.

### 2.3 엄격한 통계적 유효성 검증 (Residual Diagnostics)
- **Ljung-Box Test**: 잔차에 유의미한 자기상관성이 남아있으면 '억지 피팅'으로 간주하여 점수를 삭감합니다.
- **ARCH Test**: 잔차의 이분산성을 체크하여 모델이 설명하지 못하는 변동성을 감지합니다.

### 2.4 고정밀 수치 처리 (High Precision Display)
- 모든 출력 데이터는 **소수점 5번째 자리에서 반올림하여 4자리까지 표시**(`:.4f`)합니다.
### 2.5 피팅 안정성 고도화 (Phase 6-2 Updates)
- **중앙 설정 관리 (Centralized Config)**: 모든 피팅 파라미터(범위, 반복 횟수, 임계값 등)는 `config.yaml`을 통해 외부에서 관리됩니다. 이를 통해 코드 수정 없이 실험 환경을 즉시 변경할 수 있습니다.
- **초기값 샘플링 확장**: 파라미터 최적화 시 로컬 미니마(Local Minima)에 빠지는 것을 방지하기 위해 $t_c$, $m$, $\omega$의 탐색 범위를 라틴 하이퍼큐브(Latin-Hypercube) 방식으로 넓게 샘플링합니다.
- **O-S 조건 검증 강화**: 가격 가속도($B$) 대비 진동 진폭($C$)의 비율(`max_oscillation_ratio`)을 엄격하게 제한하여, 노이즈성 진동이 버블로 오인되는 현상을 방지합니다.

### 🛡️ [LPPL Engine] 성능 최적화 및 캐싱
- **Caching Layer**: 동일한 데이터셋과 파라미터 조합에 대해 `joblib`을 활용한 **디스크 캐싱**을 수행합니다. 이를 통해 반복적인 분석 요청 시 연산 시간을 99% 이상 단축합니다.
- **해시 기반 검증**: 입력 데이터의 MD5 해시값을 생성하여 데이터가 1일이라도 변경되면 자동으로 캐시를 갱신합니다.

## 3. 리스크 컴포넌트 상세 (Risk Components)
...
1.  **Regime Score**: 현재 시장이 버블이 형성될 수 있는 환경인가? (추세, 모멘텀, 변동성)
2.  **Fit Score**: LPPL 수식이 실제 가격 데이터와 얼마나 통계적으로 일치하는가? ($R^2$, 잔차 진단)
3.  **Stability Score**: 100회 시뮬레이션 결과 파라미터들이 얼마나 일관되게 수렴하는가? (KDE 밀집도)
4.  **Timing Score**: 예측된 임계점($t_c$)이 현재 시점과 얼마나 가까운가? (가까울수록 가중)
5.  **Consistency Score**: 다양한 분석 윈도우(120일, 250일, 500일)가 동일한 시점을 가리키는가?

## 4. 진단 등급 가이드
- **🚨 High Risk (기본값 70.0)**: 통계적 버블 확정. 추세 붕괴 위험이 매우 높음.
- **⚠️ Alert (기본값 40.0)**: 투기적 과열. 점진적 비중 축소 고려 구간.
- **✅ Normal**: 안정적 추세 또는 위험 신호 미발생.
*모든 임계값은 `config.yaml`의 `lppl` 섹션에서 수정 가능합니다.*

## 5. 포트폴리오 연동 및 추적
- 각 종목별 **변동사항(Notes)**을 관리하여 매매 히스토리(예: "2주 매도 완료")와 리스크 점수를 실시간으로 대조 분석합니다.
- 리밸런싱 가이드와 연동되어 전체 포트폴리오의 **가중 평균 위험도**를 4자리 정밀도로 산출합니다.
