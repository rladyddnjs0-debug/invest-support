# 🗺️ 마켓 히트맵 (Market Heatmap)

## 1. 개요
Finviz의 시장 히트맵처럼, S&P 500 전 종목을 섹터별로 묶어 **시가총액(박스 크기)**과 **당일 등락률(박스 색상)**을 한 화면에서 직관적으로 파악할 수 있는 트리맵(Treemap) 시각화입니다. 클릭 인터랙션 없이 순수 시각화 용도로 제공되며, 특정 기간을 선택하는 토글 없이 항상 "당일" 등락률만을 기준으로 삼습니다.

## 2. 데이터 파이프라인

정적으로 변하는 값과 실시간성이 중요한 값을 서로 다른 신선도로 관리합니다.

| 데이터 | 출처 | 갱신 주기 |
| :--- | :--- | :--- |
| 종목명 / 섹터 / 시가총액 | `DataLoader.get_stock_fundamentals()` (퀀트 스크리너와 동일한 캐시) | 최대 7일 |
| 당일 등락률 | `DataLoader.get_daily_changes()` (yfinance 배치 1회 호출) | 최대 30분 (`@st.cache_data(ttl=1800)`) |

*   **왜 분리했는가**: 시가총액/섹터 같은 펀더멘털 정보는 하루 이틀 오래돼도 트리맵의 박스 크기 비율에 거의 영향이 없지만, 당일 등락률은 신선도가 핵심이기 때문에 짧은 캐시로 별도 관리합니다.
*   **`get_daily_changes(tickers)`**: `yf.download(tickers, period="2d", interval="1d")` 단 1회 호출로 전 종목의 `(마지막 종가 / 전일 종가 - 1) * 100`을 계산합니다. 데이터가 없는 종목은 결과에서 조용히 제외되며(예외 발생 없음), 배치 호출 자체가 실패하면 빈 결과를 반환합니다. 재시도/백오프 로직은 의도적으로 두지 않았습니다(배치 1회 호출이라 리스크가 낮음).

## 3. 시각화 로직
*   **계층 구조**: `S&P 500 → Sector → 종목(회사명 + 티커)` 3단 트리맵.
*   **박스 크기**: 시가총액 (`MarketCap`).
*   **박스 색상**: 당일 등락률을 0%를 중심으로 한 발산형(Diverging) 색상 스케일(`RdYlGn`)로 표현. 상승은 초록, 하락은 빨강.
*   **타일 라벨**: 종목명(티커) 아래에 당일 등락률(`+4.84%`, `-1.39%` 형식)을 함께 표기합니다.
*   **Hover 상세정보**: 시가총액을 `$4.58T`, `$450.2B`, `$3.2M`처럼 사람이 읽기 쉬운 단위로 변환해 표시하며, 당일 등락률·PER·ROE를 함께 보여줍니다.

## 4. 에러 및 예외 처리
| 상황 | 동작 |
| :--- | :--- |
| 펀더멘털 데이터 조회 실패 | 에러 메시지 표시 후 렌더링 중단 |
| 당일 등락률 전체 조회 실패 | 전 종목 0%(중립색) 처리 + 경고 문구 표시 |
| 일부 종목만 등락률 조회 실패 | 해당 종목만 0% 처리 + "N개 종목은 0%로 표시됩니다" 안내 |
| 시가총액 결측/0 | 해당 종목은 트리맵에서 제외 |

## 5. 활용 방법
1. 사이드바에서 "🗺️ 마켓 히트맵" 선택.
2. 섹터 단위로 시장 전반의 자금 쏠림(큰 박스)과 등락 방향(색상)을 한눈에 파악.
3. 특정 섹터 내에서 상대적으로 부진하거나 강세인 종목을 색상 대비로 빠르게 식별.

## 6. 범위 및 향후 개선 방향
*   **현재 범위**: US(S&P 500)만 지원. KOSPI 200은 포함하지 않습니다.
*   **향후 검토 과제**: KR 시장 지원, 1주/1개월/YTD 등 기간 선택 토글, 타일 클릭 시 기존 종목 상세 팝업 연동.
