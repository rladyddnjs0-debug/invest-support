# 🗺️ 마켓 히트맵 (Market Heatmap)

## 1. 개요
Finviz의 시장 히트맵처럼, S&P 500 전 종목을 섹터별로 묶어 **시가총액(박스 크기)**과 **등락률(박스 색상)**을 한 화면에서 직관적으로 파악할 수 있는 트리맵(Treemap) 시각화입니다. 클릭 인터랙션 없이 순수 시각화 용도로 제공되며, 특정 기간을 선택하는 토글은 없습니다.

박스 색상/라벨은 항상 **"가장 최근에 완료된 정규장의 종가"를 기준**으로 계산되어, 프리마켓·정규장·애프터마켓은 물론 주말·연휴 동안에도 값이 0%로 리셋되지 않고 하루(또는 마지막 거래일)의 누적 변동을 계속 보여줍니다. 애프터마켓 시간에는 그 시간대에만 의미가 있는 "애프터마켓 자체 등락률"을 hover에서 별도로 확인할 수 있습니다.

## 2. 데이터 파이프라인

정적으로 변하는 값과 실시간성이 중요한 값을 서로 다른 신선도로 관리합니다.

| 데이터 | 출처 | 갱신 주기 |
| :--- | :--- | :--- |
| 종목명 / 섹터 / 시가총액 | `DataLoader.get_stock_fundamentals()` (퀀트 스크리너와 동일한 캐시) | 최대 7일 |
| 등락률(`change`, `after_hours_change`) | `DataLoader.get_daily_changes()` (yfinance 배치 호출) | 최대 30분 (`@st.cache_data(ttl=1800)`) |

*   **왜 분리했는가**: 시가총액/섹터 같은 펀더멘털 정보는 하루 이틀 오래돼도 트리맵의 박스 크기 비율에 거의 영향이 없지만, 등락률은 신선도가 핵심이기 때문에 짧은 캐시로 별도 관리합니다.

### `get_daily_changes(tickers)` 상세 로직

반환 형식: `{ticker: {'change': float, 'after_hours_change': float | None}}`

1. `yf.download(tickers, period="2d", interval="1d")` 1회 호출로 최근 2개의 **정규장 일봉 종가**를 가져온다.
2. 현재 미국 동부시간이 정규장(평일 09:30~16:00 ET)인지 `_is_regular_market_hours()`로 판단한다 (공휴일은 반영하지 않는 근사치).
3. **정규장 중**: `change` = (현재 정규장가 / 전일 정규장 종가 − 1) × 100. 기존과 동일.
4. **정규장이 아닐 때**(프리마켓/애프터마켓/주말/연휴): 우선 **기본값으로 가장 최근 완료된 정규장의 등락률을 그대로 유지**한다 (예: 금요일 장 마감 후에는 주말 내내 "목요일 대비 금요일" 등락률을 계속 보여줌 — 0%로 리셋되지 않음). 그 다음, `yf.download(tickers, period="1d", interval="1m", prepost=True)`로 연장거래 데이터를 추가 조회하여, **그 마지막 체결 시각이 실제로 "오늘"일 때만** 다음과 같이 대체한다:
    *   **애프터마켓** (오늘 정규장 종가가 이미 존재): 기준가(전일 종가)는 유지하고 현재가만 연장거래 체결가로 교체 → `change`는 하루 전체의 누적 변동을 계속 보여줌. 동시에 `after_hours_change` = (연장거래가 / 금일 정규장 종가 − 1) × 100 을 별도로 계산.
    *   **프리마켓** (오늘 정규장 종가가 아직 없음): 기준가를 "마지막 거래일 종가"로 전환하고 현재가를 연장거래 체결가로 교체.
5. 연장거래 데이터의 마지막 체결 시각이 오늘이 아니면(주말/연휴 동안의 오래된 스냅샷) 그 데이터는 무시한다 — 실제 거래가 없는데 조회 시점마다 미세하게 다른 노이즈성 등락률이 나오는 것을 방지하기 위함이다 (`_is_timestamp_today`).
6. 데이터가 없는 종목은 결과에서 조용히 제외되며, 배치 호출 자체가 실패하면 빈 결과를 반환한다. 재시도/백오프 로직은 의도적으로 두지 않았다 (배치 호출 자체가 실패하는 경우는 드물고, 실패 시에도 다음 캐시 주기에 재시도됨).

## 3. 시각화 로직
*   **계층 구조**: `S&P 500 → Sector → 종목(회사명 + 티커)` 3단 트리맵.
*   **박스 크기**: 시가총액 (`MarketCap`).
*   **박스 색상**: `change`를 0%를 중심으로 한 발산형(Diverging) 색상 스케일(`RdYlGn`)로 표현. 상승은 초록, 하락은 빨강.
*   **타일 라벨**: 종목명(티커) 아래에 `change`(`+4.84%`, `-1.39%` 형식)를 함께 표기합니다.
*   **Hover 상세정보**: 시가총액을 `$4.58T`, `$450.2B`, `$3.2M`처럼 사람이 읽기 쉬운 단위로 변환해 표시하며, `change`·PER·ROE를 함께 보여줍니다. 애프터마켓 시간에 `after_hours_change`가 존재할 때만 마지막 줄에 "애프터마켓 등락률: +x.xx%"가 추가로 표시됩니다 (그 외 시간에는 이 줄 자체가 생략됨).

## 4. 에러 및 예외 처리
| 상황 | 동작 |
| :--- | :--- |
| 펀더멘털 데이터 조회 실패 | 에러 메시지 표시 후 렌더링 중단 |
| 당일 등락률 전체 조회 실패 | 전 종목 0%(중립색) 처리 + 경고 문구 표시 |
| 일부 종목만 등락률 조회 실패 | 해당 종목만 0% 처리 + "N개 종목은 0%로 표시됩니다" 안내 |
| 시가총액 결측/0 | 해당 종목은 트리맵에서 제외 |

## 5. 활용 방법
1. 사이드바에서 "🗺️ 마켓 히트맵" 선택.
2. 섹터 단위로 시장 전반의 자금 쏠림(큰 박스)과 등락 방향(색상)을 한눈에 파악.
3. 특정 섹터 내에서 상대적으로 부진하거나 강세인 종목을 색상 대비로 빠르게 식별.

## 6. 범위 및 향후 개선 방향
*   **현재 범위**: US(S&P 500)만 지원. KOSPI 200은 포함하지 않습니다.
*   **향후 검토 과제**: KR 시장 지원, 1주/1개월/YTD 등 기간 선택 토글, 타일 클릭 시 기존 종목 상세 팝업 연동.
