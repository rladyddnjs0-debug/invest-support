# React 퀀트 스크리너 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a new `invest-support-web` repo with a FastAPI backend (wrapping the existing `invest-support/modules/` analysis engine unchanged) and a React+TypeScript frontend that reproduces the Quant Screener page from the Streamlit app — ranking table, 4 charts, position sizing — per `docs/superpowers/specs/2026-07-11-react-frontend-migration-design.md`.

**Architecture:** FastAPI exposes 3 read/write endpoints backed by the copied `modules/` package (`DataLoader`, `AnalysisModel`, `QuantScreener`). A day-scoped in-memory cache with per-key `asyncio.Lock` sits between the routers and the expensive calls (LPPL fit, fundamentals scoring) so the 3 endpoints never redundantly re-fetch or re-fit the same market on the same day. The React app is a single `ScreenerPage` that fetches from these 3 endpoints and renders the table + Plotly charts + position sizing panel.

**Tech Stack:** Python 3.14 / FastAPI / Pydantic v2 / pandas (backend, reusing existing `modules/`) — TypeScript / Vite / React / Tailwind CSS / shadcn/ui / react-plotly.js (frontend).

## Global Constraints

- New repo lives at `~/develop/workspace/invest-support-web`, separate from `invest-support` (per spec — no symlink/shared package).
- `modules/` files are copied **verbatim, no edits** — `data_loader.py`, `models.py`, `config.py`, `logger.py`, `lppl_engine.py`. Their internal imports (`from modules.config import settings`, etc.) require the `modules/` directory to sit at the **backend project root**, as a sibling of `app/` — not nested inside `app/`.
- Backend processes (uvicorn, pytest) must be run with cwd = `backend/`, because `modules/config.py` loads `config.yaml` via the relative default path `"config.yaml"`, and `DataLoaderConfig.data_dir` defaults to the relative path `"data"`.
- Regime names used by `QuantScreener.weights` and returned by `AnalysisModel.calculate_attractiveness` are the exact Korean strings `"Risk-on (안정 성장)"`, `"Risk-off (위험 관리)"`, `"Transition (국면 전환)"` — never change these strings; the API maps them to/from short slugs (`risk_on`, `risk_off`, `transition`) at the boundary so query strings stay ASCII.
- No LPPL/AI-report detail popup, no news, no progress-bar streaming, no deployment config — out of scope per spec.
- Frontend has no enforced automated test suite for MVP (per spec) — each frontend task ends with a manual browser verification step instead of a test run. Backend tasks use pytest/TDD throughout.

```python
# backend/app/cache.py
import asyncio
from datetime import date
from typing import Any, Dict, Optional, Tuple


class MarketCache:
    """Day-scoped in-memory cache with a per-key asyncio.Lock.

    Values expire when the wall-clock date changes rather than by a fixed
    TTL, since the underlying data (fundamentals, market history) is only
    ever refreshed once per calendar day at most.
    """

    def __init__(self) -> None:
        self._store: Dict[str, Tuple[date, Any]] = {}
        self._locks: Dict[str, asyncio.Lock] = {}

    def get(self, key: str, today: Optional[date] = None) -> Optional[Any]:
        today = today or date.today()
        entry = self._store.get(key)
        if entry is None:
            return None
        cached_date, value = entry
        if cached_date != today:
            return None
        return value

    def set(self, key: str, value: Any, today: Optional[date] = None) -> None:
        today = today or date.today()
        self._store[key] = (today, value)

    def lock_for(self, key: str) -> asyncio.Lock:
        if key not in self._locks:
            self._locks[key] = asyncio.Lock()
        return self._locks[key]
```

```python
# backend/app/ref_analysis.py
from typing import Any, Dict

REF_INDEX = {"us": "^GSPC", "kr": "^KS11"}


async def get_ref_analysis(market: str, cache, loader, engine) -> Dict[str, Any]:
    """기준지수(S&P500/KOSPI) 매력도 + LPPL 위험도를 계산하고 당일 캐시에 저장한다.

    regime 엔드포인트(자동 레짐)와 position-sizing 엔드포인트(총 목표 비중 산출)가
    이 결과를 공유해, 연산 비용이 높은 LPPL 피팅을 요청마다 중복 실행하지 않는다.
    """
    key = f"ref_analysis:{market}"
    cached = cache.get(key)
    if cached is not None:
        return cached

    lock = cache.lock_for(key)
    async with lock:
        cached = cache.get(key)
        if cached is not None:
            return cached

        result: Dict[str, Any] = {
            "autoRegimeLabel": None,
            "weights": None,
            "attractivenessScore": None,
            "dangerScore": 0.0,
        }

        ref_data = loader.get_market_history(REF_INDEX[market], period="2y")
        if ref_data is not None and not ref_data.empty:
            ref_attr = engine.calculate_attractiveness(ref_data["Close"], None)
            if ref_attr:
                result["autoRegimeLabel"] = ref_attr["regime"]
                result["weights"] = ref_attr["weights"]
                result["attractivenessScore"] = ref_attr["score"]

            ref_lppl = engine.run_lppl_fit(ref_data["Close"], num_iterations=20)
            if ref_lppl:
                result["dangerScore"] = ref_lppl["danger_score"]

        cache.set(key, result)
        return result
```

```python
# backend/app/screening.py
import pandas as pd


async def get_screened_df(market: str, regime_label: str, cache, loader, screener) -> pd.DataFrame:
    """market의 펀더멘털을 수집해 regime_label 가중치로 스코어링한 DataFrame을 반환한다.

    같은 (market, regime_label) 조합에 대한 재요청은 당일 캐시를 재사용해,
    수백 개 종목의 펀더멘털 재수집/재스코어링을 반복하지 않는다.
    """
    key = f"screened:{market}:{regime_label}"
    cached = cache.get(key)
    if cached is not None:
        return cached

    lock = cache.lock_for(key)
    async with lock:
        cached = cache.get(key)
        if cached is not None:
            return cached

        tickers = loader.get_sp500_tickers() if market == "us" else loader.get_kospi200_tickers()
        fund_df = loader.get_stock_fundamentals(tickers, market_name=market)
        screened_df = screener.run_screening(fund_df, regime_label, sector_neutral=(market == "us"))

        cache.set(key, screened_df)
        return screened_df
```

Use `Depends(_get_screener_dependency)`, NOT `Depends(get_screener)`, in this route. By the time this function is defined, the module-level name `get_screener` has been rebound to Task 6's route handler (`async def get_screener(...)` at `/{market}`) — Python evaluates a `def`'s default-argument expressions when the `def` statement executes, and Task 6's `def` statement, once it finishes executing, rebinds `get_screener` in the module namespace before this function's own `def` statement runs. Using the plain name here would silently inject Task 6's route handler as a "dependency" instead of the real `app.dependencies.get_screener` provider. `_get_screener_dependency` (captured in Task 5, right after `router = APIRouter(...)`, before any route shadows the name) is the safe reference.

```python
# backend/app/routers/screener.py — add imports and route
from app.schemas import (  # extend existing schemas import
    Position,
    PositionSizingRequest,
    PositionSizingResponse,
    ScreenerResponse,
    StockRow,
)


@router.post("/{market}/position-sizing", response_model=PositionSizingResponse)
async def post_position_sizing(
    market: Market,
    body: PositionSizingRequest,
    cache=Depends(get_cache),
    loader=Depends(get_loader),
    engine=Depends(get_engine),
    screener=Depends(_get_screener_dependency),
) -> PositionSizingResponse:
    regime_label = REGIME_LABELS.get(body.regime, REGIME_LABELS["transition"])

    screened_df = await get_screened_df(market, regime_label, cache, loader, screener)
    ref_analysis = await get_ref_analysis(market, cache, loader, engine)

    attractiveness_score = ref_analysis["attractivenessScore"]
    if attractiveness_score is None:
        attractiveness_score = 50.0
    total_target_weight_pct = engine.calculate_target_weight(
        attractiveness_score, ref_analysis["dangerScore"]
    )

    top10 = screened_df.head(10)
    weighted_df = screener.calculate_stock_weights(top10, total_target_weight_pct, loader, body.totalCapital)

    positions = [
        Position(
            ticker=r["Ticker"],
            name=r.get("Name", r["Ticker"]),
            recWeight=r["RecWeight"],
            shares=int(r["Shares"]),
            stopLoss=r["StopLoss"],
            targetPrice=r["TargetPrice"],
            dangerScore=r["DangerScore"],
        )
        for r in weighted_df.to_dict(orient="records")
    ]
    return PositionSizingResponse(totalTargetWeightPct=total_target_weight_pct, positions=positions)
```

```ts
// frontend/src/api/screener.ts
import type {
  Market,
  PositionSizingRequestBody,
  PositionSizingResponse,
  RegimeResponse,
  RegimeSlug,
  ScreenerResponse,
} from "./types"

const BASE_URL = import.meta.env.VITE_API_BASE_URL ?? "http://localhost:8000"

async function fetchJson<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`${BASE_URL}${path}`, init)
  if (!res.ok) {
    throw new Error(`API error ${res.status}: ${await res.text()}`)
  }
  return res.json() as Promise<T>
}

export function getRegime(market: Market): Promise<RegimeResponse> {
  return fetchJson(`/api/screener/${market}/regime`)
}

export function getScreener(market: Market, regime: RegimeSlug): Promise<ScreenerResponse> {
  return fetchJson(`/api/screener/${market}?regime=${regime}`)
}

export function postPositionSizing(
  market: Market,
  body: PositionSizingRequestBody,
): Promise<PositionSizingResponse> {
  return fetchJson(`/api/screener/${market}/position-sizing`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  })
}
```

```tsx
// frontend/src/pages/ScreenerPage.tsx
import { useEffect, useState } from "react"
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
import { Badge } from "@/components/ui/badge"
import { getRegime, getScreener } from "@/api/screener"
import type { Market, RegimeSlug, ScreenerResponse } from "@/api/types"
import { ScreenerTable } from "@/components/ScreenerTable"

const REGIME_OPTIONS: { value: RegimeSlug; label: string }[] = [
  { value: "risk_on", label: "Risk-on (안정 성장)" },
  { value: "risk_off", label: "Risk-off (위험 관리)" },
  { value: "transition", label: "Transition (국면 전환)" },
]

export function ScreenerPage() {
  const [market, setMarket] = useState<Market>("us")
  const [autoRegime, setAutoRegime] = useState<RegimeSlug | null>(null)
  const [manualRegime, setManualRegime] = useState<RegimeSlug | null>(null)
  const [screenerData, setScreenerData] = useState<ScreenerResponse | null>(null)
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState<string | null>(null)

  const effectiveRegime: RegimeSlug | null = manualRegime ?? autoRegime

  useEffect(() => {
    setAutoRegime(null)
    setManualRegime(null)
    setScreenerData(null)
    setError(null)

    getRegime(market)
      .then((res) => setAutoRegime(res.autoRegime))
      .catch(() => setAutoRegime(null))
  }, [market])

  useEffect(() => {
    if (!effectiveRegime) return

    setLoading(true)
    setError(null)
    getScreener(market, effectiveRegime)
      .then((res) => setScreenerData(res))
      .catch((err) => setError(err instanceof Error ? err.message : "알 수 없는 오류"))
      .finally(() => setLoading(false))
  }, [market, effectiveRegime])

  return (
    <div className="mx-auto max-w-6xl space-y-6 p-8">
      <div className="flex items-center gap-4">
        <Select value={market} onValueChange={(v) => setMarket(v as Market)}>
          <SelectTrigger className="w-40">
            <SelectValue />
          </SelectTrigger>
          <SelectContent>
            <SelectItem value="us">US (S&P 500)</SelectItem>
            <SelectItem value="kr">KR (KOSPI 200)</SelectItem>
          </SelectContent>
        </Select>

        <Select
          value={effectiveRegime ?? undefined}
          onValueChange={(v) => setManualRegime(v as RegimeSlug)}
        >
          <SelectTrigger className="w-56">
            <SelectValue placeholder="레짐 선택" />
          </SelectTrigger>
          <SelectContent>
            {REGIME_OPTIONS.map((opt) => (
              <SelectItem key={opt.value} value={opt.value}>
                {opt.label}
              </SelectItem>
            ))}
          </SelectContent>
        </Select>

        {autoRegime && !manualRegime && (
          <Badge variant="secondary">자동 계산된 레짐 적용 중</Badge>
        )}
        {!autoRegime && (
          <Badge variant="destructive">레짐 자동 계산 실패 — 수동 선택 필요</Badge>
        )}
      </div>

      {loading && <p className="text-sm text-muted-foreground">스크리닝 중...</p>}
      {error && <p className="text-sm text-destructive">{error}</p>}

      {screenerData && !loading && <ScreenerTable rows={screenerData.rows} />}
    </div>
  )
}
```

- **Correction (post-Task-7 implementation):** the original version of this plan named Task 6's route handler `get_screener` — the same name as the `app.dependencies.get_screener` DI provider imported at the top of the same file. Since Python evaluates a function's default-argument expressions (including `Depends(...)`) at `def`-statement execution time, and Task 6's `def get_screener(...)` statement rebinds the module-level name `get_screener` once it finishes executing, Task 7's later `def post_position_sizing(..., screener=Depends(get_screener))` would have silently resolved `get_screener` to Task 6's route handler instead of the DI provider — FastAPI would then have recursively merged that handler's own parameters (including a bare `regime: RegimeSlug`) into position-sizing's dependency graph, producing a spurious 422 on valid POST bodies. Task 7's implementer caught this via direct reproduction (not just suspicion) and fixed it by adding `_get_screener_dependency = get_screener` immediately after `router = APIRouter(...)` in Task 5's code (before any route can shadow the name), and pointing only the position-sizing route at that captured reference. Both this plan file and the already-committed code were corrected to match; Task 6's own route is unaffected (its own `Depends(get_screener)` is evaluated before its own `def` statement completes the rebind, so it still resolves correctly).
