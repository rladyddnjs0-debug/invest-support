# 퀀트 스크리너 백테스트 — Look-ahead Bias 정직화 설계 문서

## 배경

`종목 스크리너` 페이지의 "1년 전 성과 백테스트" 기능은 `DataLoader.get_historical_fundamentals(tickers, base_date, market_name)`를 호출해 "1년 전 시점의 랭킹"을 재구성한다고 UI/문서에 설명되어 있다. 그러나 실제 구현은 `base_date`를 전혀 사용하지 않고 `get_stock_fundamentals()`(오늘 시점 최신 펀더멘털)를 그대로 반환한다:

```python
def get_historical_fundamentals(self, tickers, base_date, market_name="us"):
    """과거 시점 재무제표 재구성 대신, 인터페이스 호환을 위해 현재 펀더멘털 데이터를 반환합니다."""
    return self.get_stock_fundamentals(tickers, market_name=market_name)
```

즉 이 기능은 "1년 전에 이 전략을 썼다면 어땠을까"가 아니라 "**오늘 기준으로 좋은 종목이 지난 1년간 어떻게 움직였는가**"를 보여준다. 현재 펀더멘털이 좋은 기업은 최근 주가도 함께 오른 경우가 많으므로, 이 결과로 계산되는 초과수익(알파)은 실제 전략의 예측력보다 낙관적으로 나오는 사전관찰 편향(look-ahead bias)을 갖는다.

## 결정: 계산 로직 유지, 사용자에게 정확히 설명

진짜 point-in-time 펀더멘털 복원(과거 분기 재무제표 + 과거 주가 결합)은 데이터 공백·정합성 리스크가 크고(특히 한국 pykrx), 엔지니어링 부담도 커서 이번 범위에서 제외한다. 대신:

- 계산 로직(수익률/샤프지수/MDD 계산)은 **변경하지 않는다** — 숫자 자체는 정확하다.
- **UI 문구와 문서에서 "1년 전 시점 백테스트"라는 사실과 다른 표현을 제거**하고, "오늘 기준 상위 종목의 최근 1년 실제 성과(참고용)"로 정확히 재설명한다.
- look-ahead bias가 있다는 사실을 화면에 명시적인 경고로 노출한다.

`get_historical_fundamentals`의 코드 docstring은 이미 정직하므로 변경하지 않는다. `backtester.py`의 `run_backtest` docstring에도 동일한 취지의 주석을 보강한다.

### 2. `modules/backtester.py` — `run_backtest` 메서드 docstring

기존 docstring `"1년 전 시점의 Top 10 종목을 선정하고 현재까지의 성과를 계산합니다."`를 아래로 교체:

```python
"""
'오늘 시점'의 펀더멘털로 선정한 Top 10 종목이 지난 1년간 기록한 실제 수익률을 계산합니다.
주의: 종목 선정에 사용하는 펀더멘털은 항상 최신 데이터이며 base_date 시점으로 되돌아가지
않으므로, 이는 전략의 사전 예측력을 검증하는 진짜 point-in-time 백테스트가 아니라
참고용 성과 조회 기능입니다 (look-ahead bias 있음).
"""
```

### 3. `docs/quant_screener.md` — 5절 "성과 검증 (Backtesting)"

현재:
```markdown
## 5. 성과 검증 (Backtesting)
전략의 신뢰도를 높이기 위해 '1년 전 시점'의 데이터를 활용한 성과 검증 기능을 제공합니다.
*   **포인트-인-타임 분석**: 1년 전 기준일의 펀더멘털(KR) 및 모멘텀 데이터를 추출하여 당시의 Top 10 종목을 선정합니다.
*   **누적 수익률 비교**: 선정된 10개 종목의 동일 비중 포트폴리오 성과를 해당 시장 지수(KOSPI 또는 S&P 500)와 실시간으로 비교 시각화합니다.
*   **알파(Alpha) 도출**: 시장 대비 초과 수익률을 계산하여 현재 설정된 레짐 가중치의 유효성을 검증합니다.
```

변경 후:
```markdown
## 5. 현재 상위 종목의 최근 1년 성과 (참고용, 진짜 백테스트 아님)
현재 레짐 가중치로 **오늘 시점** 펀더멘털을 기준으로 Top 10을 선정한 뒤, 그 종목들의 최근 1년 실제 수익률을 보여주는 참고 기능입니다.
*   **⚠️ Look-ahead Bias 주의**: 종목 선정 자체가 오늘 시점 데이터로 이뤄지므로, "1년 전에 이 전략을 썼다면 어땠을까"를 검증하는 진짜 point-in-time 백테스트가 아닙니다. 현재 펀더멘털이 좋은 종목은 최근 주가도 함께 오른 경우가 많아, 여기서 계산되는 초과수익은 실제 실전 성과보다 낙관적으로 나올 수 있습니다.
*   **누적 수익률 비교**: 선정된 10개 종목의 동일 비중 포트폴리오 성과를 해당 시장 지수(KOSPI 또는 S&P 500)와 비교 시각화합니다. 계산 자체(수익률/샤프지수/MDD)는 정확하지만, "레짐 가중치의 유효성을 검증한다"는 의미로 해석해서는 안 됩니다.
*   **향후 개선 과제**: 과거 분기 재무제표 + 과거 주가를 결합해 진짜 point-in-time 펀더멘털을 복원하는 것이 근본적인 해결책이며, `docs/quant_screener.md` 11절(향후 개선 방향)에 이미 등재되어 있습니다.
```

## 비목표 (Out of scope)

- 진짜 point-in-time 펀더멘털 복원 (과거 분기 재무제표 결합) — 별도 과제로 분리 (섹터 중립화, 모멘텀 팩터 개선, 레짐 자동 연동, 리스크 패리티 개선과 함께 후속 검토)
- 계산 로직(수익률/샤프지수/MDD) 자체의 변경
- `get_historical_fundamentals` 함수명 변경 (docstring이 이미 정직하므로 변경 불필요)
