# 🤖 AI 투자 에이전트 (AI Agent)

## 1. 개요
AI 투자 에이전트는 Google Gemini 1.5 모델을 활용하여 정량적 데이터(수치)를 정성적 인사이트(리포트)로 변환합니다. 단순한 데이터 요약이 아닌, **헤지펀드 리스크 매니저**의 페르소나를 통해 비판적이고 전략적인 투자 조언을 제공합니다.

## 2. 주요 기능 로직

### ① 시장 분석 리포트 (Gemini 1.5 Flash)
*   **입력 데이터**: LPPL 파라미터($t_c$, $m$, $B$, $\omega$), 시장 매력도 점수, 글로벌 매크로 5대 지표.
*   **분석 프로세스**:
    1.  **매크로 점검**: 현재가 금융 긴축인지 완화 국면인지 정의.
    2.  **버블 신뢰도 평가**: 수학적 파라미터가 전형적인 버블 패턴을 보이는지 비판적으로 검토.
    3.  **상관관계 분석**: 서로 충돌하는 지표(예: 강달러와 주가상승) 간의 모순을 포착.
    4.  **최종 리스크 분류**: [공격적 매수 / 정상 상승 / 버블 말기 / 리스크 회피] 중 선택.

### ② 포트폴리오 진단 (Gemini 1.5 Pro)
*   **입력 데이터**: 사용자의 보유 종목 리스트, 수익률, 비중, 개별 종목 LPPL 위험 점수.
*   **분석 프로세스**:
    1.  **자산 배분 효율성**: 특정 종목이나 섹터에 대한 과도한 쏠림 진단.
    2.  **수익/위험 균형**: 수익률이 높은 종목 중 LPPL 위험 점수가 급증한 종목에 대해 '수익 실현' 제안.
    3.  **위험 종목 대응**: 위험 점수 70점 이상의 종목에 대해 구체적인 손절 및 비중 축소 전략 제시.

> **참고**: 개별 종목의 최신 뉴스는 더 이상 자체 수집·AI 요약하지 않습니다. 종목 상세 팝업의 "📰 세이브티커에서 뉴스 보기" 버튼이 [saveticker.com](https://www.saveticker.com)의 해당 종목 뉴스 탭을 새 탭으로 엽니다.

## 3. 프롬프트 엔지니어링 전략
*   **Persona**: "데이터 기반의 차갑고 전문적인 어조를 유지하는 헤지펀드 전략가" 설정.
*   **Constraint**: 감정적 서술 배제, 오직 수치적 근거에 기반한 논리적 서술 강조.
*   **Output**: 마크다운 형식을 활용한 가독성 높은 리포트 구조화.

## 4. 활용 한계
*   AI 리포트는 제공된 정량적 데이터 내에서 최선의 해석을 제공하지만, 미래를 확정적으로 예언하지는 않습니다. 모든 최종 판단은 투자자 본인이 내려야 합니다.
